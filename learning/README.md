# Learning route

The selected educational anchor is Stephen D. Bartlett, Terry Rudolph and Robert W. Spekkens, *Reference frames, superselection rules, and quantum information*, Reviews of Modern Physics **79**, 555–609 (2007), [arXiv:quant-ph/0610030v3](https://arxiv.org/abs/quant-ph/0610030v3). The [bridge](bridge.md) selects the useful sections, translates their notation and connects the reference-frame framework to this project's physical dephasing model.

The [30-milestone map](milestones.md) is a common map of the scientific story. Its targets depend on the objects and arguments in this project, and each target points to the corresponding scientific account. It is not a replacement for the proofs or a record of any reader's progress.

The map allocates **14 milestones to background/preliminaries** and **16 to narrative/innovation**. The background first builds a single link and one laboratory's phase action, then combines fixed-charge encoding, bipartite operations, entropy and sparse-graph probability into the framework required by the question. The narrative starts with one orientation fiber, assembles the exact entanglement identity and the two degree bounds, and ends with errors, resource accounting and the full scope of the density statement.

The anchor's journal/PDF section labels use letters, while its converted arXiv HTML uses numbers: for example, PDF §II.B is HTML §II.2 and PDF §III.C.3 is HTML §III.3.3. The milestone map states both where it first uses a section. All later BRS references use the PDF/journal labels. The review supplies reference-frame and sector-entanglement foundations; the orientation-entropy identity, graph-degree bounds and stated robustness margins are derived in the project sources.
